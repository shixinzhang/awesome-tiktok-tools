# Contribution Guidelines

Thanks for taking the time to contribute. Please read these rules before
opening a PR — they follow the
[awesome-list manifesto](https://github.com/sindresorhus/awesome/blob/main/awesome.md).

## Ground rules

- The submission must be a tool, library, dataset, or learning resource
  related to **transcribing, analyzing, or repurposing TikTok videos**.
- The project must be high-quality, actively maintained, and useful to a
  real audience.
- We **do not** accept submissions that exist only as a marketing page,
  or duplicates of an already-listed tool.

## Submission format

Each entry must follow this exact format under the correct category:

```
- [Name](https://example.com/) - One-sentence objective description.
```

- The name is a link to the tool's primary URL.
- The description is one sentence, no more than ~14 words.
- **Avoid superlatives** like "best", "#1", "amazing", "must-have".
- End the sentence with a period.

## Pull request checklist

- [ ] Single entry per PR (multi-entry PRs only accepted from the maintainer).
- [ ] Entry is alphabetized within its category, or placed in a deliberate
      order if the category has one.
- [ ] No duplicate links.
- [ ] PR title is `Add ToolName to <Category>`.
- [ ] You disclose any affiliation with the tool in the PR description.

## Removal policy

If a tool becomes inactive, paywalled in a way that hides its core value,
or starts engaging in malicious behavior, open an issue and we'll evaluate
removing it.
